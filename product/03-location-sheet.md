# 2 · Floor plan

Draw the room from above, with north marked. Put a circle where you plan to stand for each shot and label it S1 to S6. Then draw the line your character faces along — every camera should be on the same side of it.

```

                 NORTH
      +----------------------------------------------+
      |                                              |
      |                                              |
      |                                              |
      |                                              |
      |                                              |
      |                                              |
      |                                              |
      +----------------------------------------------+
                 SOUTH

   Fixed things to mark:   door [D]   window [W]   fixed furniture [#]
                           practical lights (o)   camera positions S1-S6
```

*Copy this outline into any drawing app, or print the page and draw on it. What matters is where the cameras are, not how neat the plan is.*

> **Tip — The two-second check**  
> Look at the circles. If any circle is on the opposite side of the character from the others, either move it or write down why you crossed the line — the next person to open this file, including you in three days, will not remember.

## Before you move on

- Does every landmark have a frame position, not just a name?
- Is there a rule that stops the room mirroring between shots?
- Does the floor plan show one side of the line that all six cameras stay on?
- Is there anything in the room that records time — a clock, a screen, a phone — that you have not decided about?
- Do you know which light is the key, and which lights are off in the shot you are about to generate?
