# The Continuity Bible — what is in the box

**A six-shot handoff system for independent AI filmmakers** · v1.0 · November 2026

Six generated shots can look like six different films. The usual cause is not the model: it is that nobody
wrote down what has to survive the cut. This is the writing-down part — a character sheet, a location sheet,
a six-shot state table, a preflight checklist, and one complete worked example of a scene carried across six
connected shots.

It is a document, not an app. You can print it, write on it, or edit the Markdown and keep your own version.

## The four status markers

Every field you may need to mark takes one of four letters. The letter is the marker; colour is never the
only signal.

| Marker | Means | What you must write alongside it |
| --- | --- | --- |
| **F** | Fixed | Nothing. This is identity, held for the whole scene. |
| **C** | Changed intentionally | The variant code (V2, L2, P-01b) and what caused the change. |
| **U** | Unresolved | What is undecided, and what you will accept if it stays undecided. |
| **N/A** | Not applicable | Why it cannot apply to this shot. |

## What this will not do

- It will not stop a model from drifting. Continuity is a production judgment; this is the written record
  that judgment works from, and a way to notice a problem before the shot is wasted.
- It will not make six shots match by itself. You still have to check the frames.
- It assumes nothing about which model or tool you use. Any model-specific word in the example is an
  optional detail, never a requirement.
- It is written for scenes of roughly four to eight shots. Longer sequences work, but you will want one
  table per scene, not one per film.

## Printing

A4, 18 mm margins. Print single-sided if you write on the sheets; the templates have blank rows and boxes
sized for handwriting. If you print the PDF double-sided, print the character and location sheets
separately so a sheet does not share a page with text on its back.
